    Conexão com o GitHub

    Para publicar, o painel precisa de um token do GitHub com permissão de escrita somente neste repositório. O token fica salvo só neste navegador.

    Como criar o token (uma vez só)
    1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token.
    2. Em Repository access, escolha Only select repositories → Express-bateria-Rio.
    3. Em Permissions → Repository permissions, defina Contents: Read and write. Não marque mais nada.
    4. Gere o token, copie e cole aqui. Para revogar, é só excluí-lo no GitHub.
